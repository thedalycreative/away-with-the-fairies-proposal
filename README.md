# Away With The Fairies - RTRFM Proposal

A podcast proposal for RTRFM 92.1 exploring Perth's queer history across four decades.

## Deployment Instructions

### Option 1: GitHub Pages (Recommended)
1. Go to https://github.com/new
2. Create a repository named `away-with-the-fairies-proposal`
3. Don't initialize with README
4. Run these commands:
```bash
git remote add origin https://github.com/YOUR_USERNAME/away-with-the-fairies-proposal.git
git branch -M main
git push -u origin main
```
5. Go to repository Settings → Pages
6. Under "Source", select "main" branch
7. Click Save
8. Your site will be live at: `https://YOUR_USERNAME.github.io/away-with-the-fairies-proposal/`

### Option 2: Netlify Drop
1. Go to https://app.netlify.com/drop
2. Drag and drop the entire folder
3. Instant deployment!
